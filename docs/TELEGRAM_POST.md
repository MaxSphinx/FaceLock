# 🛡️ FaceLock — Face ID для приложений и ловушка для взломщиков на macOS

Написал небольшую утилиту для MacBook на чистом Swift без единой внешней зависимости: **FaceLock**.

### В чём суть:
В macOS нет защиты отдельных приложений лицом. FaceLock превращает камеру в активный биометрический щит:
• ⚡️ **Мгновенная проверка**: переключились на Safari, Telegram или Terminal — камера за 0.8с проверяет лицо через Apple Vision прямо на Neural Engine и сразу пускает.
• 📸 **Фото взломщика**: если перед ноутбуком сидит посторонний, экран намертво блокируется (уровень screensaver, Cmd+Q не работает), камера делает фото чужака с ночным HDR-лифтингом (+1.3 EV).
• 💬 **Алерт в Telegram**: фото взломщика, время попытки входа и приложение сразу прилетают вам на телефон в Telegram-бот.
• 🚶 **Walk-away Guard**: отошли от ноута на 45 секунд — FaceLock тихо чекает камеру и гасит экран.
• 🔒 **100% On-Device**: все 128-D векторы хранятся локально, никаких облаков и телеметрии.

Установка в 1 строку:
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/MaxSphinx/FaceLock/main/scripts/install.sh)"
```
